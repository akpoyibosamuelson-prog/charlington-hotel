# Charlington Hotel & Suites website

Responsive static website starter with sections for rooms, dining, events/halls, about, and a WhatsApp enquiry form.

## Before publishing
1. Open `script.js` and replace `HOTEL_WHATSAPP`, `HOTEL_PHONE`, `HOTEL_EMAIL`, and `HOTEL_ADDRESS` with verified hotel details.
2. Update any placeholder text and confirm actual room types, menu items, rates, opening hours, facilities, and event capacity with the hotel.
3. Replace the sample Unsplash photos with real hotel photos when available.

The form sends an enquiry to WhatsApp; it does not accept payments or automatically confirm bookings.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository named `charlington-hotel-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes and revisit Settings → Pages for the public website link.

Google Fonts and sample photos load from external services and require an internet connection.
